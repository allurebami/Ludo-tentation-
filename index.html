Les règles, simplement.

Tu joues avec les 4 pions corail. La machine joue avec les 4 pions violets. Le premier à faire arriver ses quatre pions gagne.

  1. Fais un 6 pour sortir un pion. Si un seul pion peut jouer, il avance automatiquement. Sinon, touche le pion à déplacer ou son bouton sous le dé.
  2. Un 6, une capture ou une arrivée donne un nouveau lancer. Trois 6 consécutifs font passer le tour.
  3. Tomber sur un adversaire le renvoie à sa maison. Les cases ★ sont protégées. Les pions peuvent partager une case ; ils ne bloquent pas le passage.
  4. Il faut le nombre exact pour atteindre le centre. Un pion arrivé ne bouge plus.

Le mode Tentation

Avidité. Chaque pion capturé vaut 20 points : garde le bonus ou risque-le sur un dé séparé (4–6 : double ; 1–3 : zéro).

Orgueil. Ton champion doit arriver avant tes autres pions sans avoir été capturé : +50 points.

Vengeance. Capture le pion qui a capturé l’un des tiens : +20 points supplémentaires.

Chaque arrivée rapporte 30 points. La machine a les mêmes défis. Le score n’influence ni les dés ni la victoire : seuls les quatre pions arrivés décident du gagnant.

Les points sont fictifs. Aucun paiement ni gain d’argent.
